## Fork Information
This is a forked version of the original project with the following improvements:

### New Features
- 🔐 Security: Bot runs only on your computer
- 🚀 Remote Control: Shutdown, restart, or put your PC to sleep
- 👤 Personalization: Store and display user names in notifications
- ⏱️ Real-time Notifications: Show notifications before and after command execution
- 📝 Logging: Automatically log all activities to a log file

### Improvements
- `/start` - Start the bot and show command menu
- `/sd` or `/shutdown` - Shutdown the computer
- `/rs` or `/restart` - Restart the computer
- `/sl` or `/sleep` - Put the computer to sleep
